- `tools/build-character-animations.mjs`로 원본 PNG를 4칸/2칸 분리했다. 인접 프레임의 발끝/그림 찌꺼기를 서로 잘못 가져오는 문제를 발견해 연결된 **가장 큰 인물 덩어리만 남기는 방식**으로 수정 후 재생성했다.
- 색·의상·표정·왕관 등 기존 그림은 다시 그리지 않았다. 출력은 투명 PNG, 스쿼트·점프 448×768 / 골대 832×928 고정 캔버스로 재정렬했다.
- 갈색/초선 각각 **정면 4컷·후면 4컷 스쿼트**, **정면 4컷·후면 4컷 쪼그려 뛰기**, **골대 낮음·높음 2컷**, **돌아보기 1컷** 저장.
- 일반 스쿼트 GIF 4개, 도약이 추가된 빠른 쪼그려 뛰기 GIF 4개, 엎드린 골대 움직임 GIF 2개 = **총 10개 GIF**. 제작 자동화 셸 명령은 `tools/render-character-gifs.sh`.
- 품질 검증 `node tools/test-character-animations.mjs` **통과: 투명도·프레임 테두리·발 기준선 48회 검사 / GIF 재생 프레임 수 10회 검사**.
- `animation_preview.html`에서 캐릭터·동작과 가상 800×800 판/블록 행수/골대 위치를 선택해 볼 수 있다. 미리보기 스크립트 문법 검사는 통과.
- 전체 원본/프레임 매니페스트: `assets/characters/animations/manifest.json`.

### 2. 검토: 판 설계 방향

- 현재 게임은 800×800, 블록 10열, 행수 7/8/9/10의 마지막 하단 y=368/412/456/500, 목표 중심 y=620/660을 사용한다.
- 새 골대 그림을 그대로 크게 올리면 **9~10행 블록과 겹친다**. 인물 골대 중심판은 7~8행, 한 명 폭 180~200px, 두 명 각 175~190px부터 실제 판에서 검증하는 안을 정리했다.
- 엔진의 충돌 타원은 그림 동작과 무관하게 고정되어 있다. 그림 프레임에 따라 표적 위치를 추적하는 설계가 필요하므로 **아직 골대 그림을 게임에 붙이지 않았다**.
- 세부 근거와 다음 설계 순서는 `docs/ANIMATION_BOARD_REVIEW_2026-11-01.md`.

### 3. 기존 40판 기본 테스트 보정

- 장면 순서를 장소별 5연속→8장소 순회/난이도 5단계로 바꾼 직전 미검증 코드를 읽고, 테스트의 옛 장면 번호 가정을 `sceneKey` 조회로 바꿨다.
- `node tools/test-stages40.js` 기본 규칙·40판 블록 수·목표 판정 **통과**. **게임 플레이/수작업 예술적 배치 완료를 뜻하지 않는다.**
- 수작업 배치는 **첫 8판까지만** 작성됐다. 나머지 32판과 캐릭터 출연표는 미완료다.

### 4. 실패/미실시/저장 상태

- Playwright를 통한 브라우저 화면 캡처를 시도했으나 설치된 브라우저 실행 파일이 없어 중단했다. 브라우저/Android 눈검사는 **미실시**.
- GitHub push **시도하지 않음**. 로컬 변경은 아직 별도 원격 백업이 아니다.
- 오프라인 파일 묶음을 만들고 `unzip -tq` 무결성 확인 **통과**:
  - `GAIA_Animation_Assets_2026-11-01.zip` (약 47MB): 원본 11개·애니메이션 PNG/GIF·자동화 스크립트·미리보기 HTML·이 기록·설계 검토.
  - `GAIA_Working_Project_Checkpoint_2026-11-01.zip` (약 97MB): 현재 미커밋 변경까지 포함한 프로젝트 전체 작업본. `.git` 내부 객체만 제외.
- **ZIP은 GitHub에 올라간 것이 아니다.** 작업 중단 시 이 ZIP 또는 저장소의 이 문서에서 재개한다.

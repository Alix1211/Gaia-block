# GAIA CITY · HEART BREAKER — 대사집 기준 40스테이지 제작 설계서

> 상태: **설계 초안 / 구현 전 검토용** · 2026-11-01 KST
>
> 이 문서가 다음 작업의 기준점이다. 이 단계에서는 기존 게임 코드·대사·원본 에셋을 수정하지 않는다.
> 스테이지마다 **대사 → 필요한 게임 사건 → 장면 연출 → 물리 규칙 → 블록 구성 → 테스트** 순으로 확정한다.

## 0. 흔들리면 안 되는 제작 원칙

1. **원본 우선**: `js/dialogues-data.js`의 NORMAL·EX-HARDCORE 각 40편에 기록된 `male / female / trigger / clear / extras`를 임의 개작·요약·삭제하지 않는다. 어떤 모드에서도 무대가 바뀌면 해당 `sceneKey`의 대사가 반드시 등장해야 한다. EX-HARDCORE는 사용자 선택 시 **같은 사건과 같은 분량**으로 재생한다.
2. **40개 엔진을 만들지 않는다**: 다섯 판을 하나의 체험 묶음으로 설계해 약 6~8개의 재사용 가능한 핵심 시스템을 구현한다. 같은 시스템 안에서는 난도뿐 아니라 **실루엣, 색 재질, 크기, 통로, 표적 수, 가림, 움직임**이 달라져야 한다. 각 판은 고유 판면을 가진다.
3. **캐릭터가 무대의 중심**: 캐릭터는 블록 판 **위쪽·중간·뒤쪽**, 때로는 블록에 가려진 위치에 놓인다. 블록 밑, 패들 근처에 별도 장식처럼 서 있는 배치는 금지한다. 블록을 깨면 인물이 나타나고, 공이 실제 신체 영역에 충돌한다. 캐릭터가 2명이면 물리 오브젝트도 2개다.
4. **의상과 대사는 실제 순서**: **옷 입은 로지로프(갈색/빨강) 또는 초선 등장 → 남성 한마디 → 여성 한마디(필요하면 추가 대화) → 기존 속옷 그림으로 전환 → 플레이 → 사건 대사와 표정 → 종료 대사 → 세계관의 0.1초 일상 복귀**. 시작을 누르는 순간 도입 대사를 생략하거나 게임 뒤에 깔아두지 않는다.
5. **기존 화풍을 그대로**: 20개 블록 PNG, 기존 포트레이트 20컷, 두 캐릭터의 스쿼트/쪼그려 뛰기/골대 프레임과 음성·효과음을 재사용한다. 새 초상화 요청이나 임시 그림 덧칠은 하지 않는다. 기본 얼굴 한 장을 계속 고정하지 않는다.
6. **내러티브는 가이아 시티**: 밝고 과장된 키치·자발적 신청·업무적 태도와 급격한 일상 복귀의 대비. 임의의 세계대회, 새로운 결승 토너먼트, 승부 인물관계는 추가하지 않는다. 기존 대사에 나오는 현장 기록·촬영·심사 표현은 **해당 장소의 단발성 행사**로 해석한다.
7. **한 번에 고치지 않는다**: 전체 설계표 승인 → 공통 연출 규격 확정 → 1장(01~05) 실제 플레이와 검증 → 다음 5판. **각 장 종료 시 화면 검수·테스트·체크포인트·GitHub 저장**. 완료하지 않은 곳은 반드시 미구현으로 표시한다.

## 2. 공통 게임 장면·판정 규격

### 2.1 무대의 공간

- 기준 논리 화면 800×800. 패들/공 출발대는 하단 710~780. 캐릭터는 **블록 군집 안이나 뒤**에 놓이며, 1인 장면은 중심 x≈400, 2인 장면은 x≈245·555에서 시작. 블록 실루엣과 충돌 방해물이 인물을 가리거나 열어 준다. 인물이 블록 아래에 떨어져 남는 좌표는 사용하지 않는다.
- 캐릭터 그림은 블록보다 **뒤에서 먼저 그리기**. 깨기 전에는 몸 일부만 보이거나 완전히 숨고, 깨지면 새로운 자세·표정이 보인다. 보드 내 가시성은 실제 블록 가림으로 구현하며, 모든 인물을 오직 임의의 퍼센트에서 갑자기 생성하지 않는다.
- 한 판은 `판 실루엣(벽·계단·아치·고리·띠)` + `블록 3크기` + `재질/색` + `움직이는 개별 블록/장애물` + `인물 동선`의 조합으로 수작업 저장한다. 무작위 빈칸 32판은 폐기 대상. **같은 크기 10열 빼곡한 화면 금지**.
- 물리 엔진은 공/블록/캐릭터/골대 목표를 별도 판정. 다중 목표에서 표적별 기록을 UI에 보이고 **한 번 달성한 횟수는 다시 초기화하지 않는다**.

### 2.2 신체별 반사·리액션 (해당 스테이지에서만 활성)

| 영역 | 그림 기반 충돌 처리 | 차이점/소리 | 화면 변화 |
|---|---|---|---|
| 상체/어깨 | 스쿼트 프레임의 상단을 따라 움직이는 다각형/타원 | 짧고 높은 튕김, 가벼운 타격 효과 | 놀람 `hit` 표정 |
| 허리/옆구리 | 자세에 따라 측면 위치 변경 | 수평 방향 반사각 변동, 옆 튕김 | 시선 바꾸기 `shy` |
| 골반/엉덩이 | 골대/후면 프레임의 중심을 따라가는 실제 타격 면 | 탄성 반사 + 기존 `slap-1..3` 구분 재생 | 강한 반동/몸 프레임, `hit` 또는 `shy` |
| 다리/허벅지 | 쪼그린 자세에서만 접근하는 낮은 영역 | 아래에서 위로 띄우는 반사, 다른 타격 음높이 | 몸 들썩임/다음 자세 |

**설계상 별개 규칙**: 골대는 **아래→위 통과**만 득점하고 충돌 후 공이 안전하게 빠진다. 몸 반사는 실제 신체를 맞혔을 때 튕기며 위치·각도·소리가 영역별로 다르다. 몸을 때렸다고 무조건 골 득점으로 취급하지 않는다. 같은 공이 한 프레임에 블록·몸을 중복 맞은 것처럼 판정하지 않는다.

### 2.3 도입·사건·종료 대사

1. `introClothed`: 무대명·의상 입은 초상·`entry.male`·`entry.female` 전체를 순차 노출. 대사 길어도 말줄임 없음. 세계관의 0.1초 전환과 플레이 개시를 독립 애니메이션으로 구분.
2. `outfitReveal`: 사용자 제공 속옷 초상과 인게임 인물 그림으로 교체. 두 사람 장면은 각자 대상 초상이 바뀐다. 시작 버튼은 대사를 다 본 뒤 활성.
3. `stageTrigger`: 아래 표에 적은 **실제 충돌·득점·공개 시점**에 `entry.trigger` 전문 표시. 이벤트가 연속 도착하면 **대기열에 넣어 생략하지 않음**. 이미 나왔어야 할 첫 사건 대사는 빠르게 재생하고, 감추었던 후속 사건이 있으면 뒤이어 노출. 복수 표적은 매 득점의 수치를 계속 표시.
4. `stageClear`: 해당 목표를 모두 채운 뒤 `entry.clear` 전문과 해당 `extras`를 누락 없이 표시. 특히 40판의 `extras[0]`와 `clear`의 순서를 정하고 둘 다 보인다. 기록 화면은 별도의 공통 문구로 대사를 덮지 않는다.
5. `normal/hardcore` 전환은 문장만 교체하고 사건 타이밍은 공유한다. EX-HARDCORE 원문 파일은 쓰기 보호 대상으로 다룬다.

## 3. 대사집 기준 8개 장 / 40개 장면별 설계

### 제1장 — 01~05 핑크 마트 / 기본 블록의 크기·재질·배치

**공통 엔진**: 순수 블록격파, 재질별 충돌 횟수, 폭발·연쇄. 5판 모두 서로 다른 실루엣. 처음부터 표적 캐릭터를 패들 아래에 놓지 않는다. 쇼핑 매대/진열대 사이에 인물이 있고 블록 파괴가 인물을 드러낸다.

| 판 / 원본 키 | 대사집의 구체적 사건 → 실제 조건 | 맵·비주얼·난도 차이 |
|---|---|---|
| 01 `MART_BASIC` | **매대 60개**, 일반 블록 연쇄 타격 → 첫 `solid` 파괴 연출/트리거 | 낮고 넓은 매대 3열, 중간 넓은 계단 틈, **정사각·일반·긴 직사각형** 혼합. 실제 파괴 대상 60개라는 수치와 대사 일치. 쉬운 직선 경로. 정장 로지로프의 첫 등장 |
| 02 `MART_JELLY` | 젤리는 **첫 타에 튕기고 두 번째에 파괴** → 첫 젤리 피격 때 속도 증가와 트리거 | 젤리 U자 진열대, 가운데 비운 고리, 반쪽 블록과 긴 젤리 바. 낮은 난도에서 공 궤도 읽기 |
| 03 `MART_METAL` | 금속 **3타** → 균열 단계별 그림·세 번째 파괴, 첫 균열에서 대사 | 금속 양 측면 기둥 + 가운데 진열대, 뒤에서 얼굴이 살짝 드러남. 보라·분홍과 금속 대조, 회피 통로 |
| 04 `MART_BOMB` | 인접 폭탄의 **연쇄 폭발**이 반드시 일어나도록 배치 → 연결 폭발에만 트리거 | 별 모양 폭탄 핵·사선 브리지. 폭탄끼리 실제 폭발 반경 겹침, 좌우 긴 블록으로 폭발 전개가 보임 |
| 05 `MART_FINALE` | 젤리·금속·폭탄 혼합, **1.2초 이내 5개 연속 파괴** → 5연쇄 때 트리거 | 계단+격자+홀로 갈라진 3구역. 폭탄 중심에 한 타짜리 블록 4~5개로 연쇄 보장; 좁은 길과 다채로운 큰 블록이 결합 |

### 제2장 — 06~10 하트 공원 / 몸으로 만드는 **실제 골대**

**공통 엔진**: 기존 `animations/{brown,choseon}/goal/low.png,high.png`를 **블록 뒤·중간**에 배치, 프레임마다 골 통로가 움직임. 골은 득점 수와 블록 파괴율을 **동시에** 만족해야 클리어. 06만 특별한 시범판이 아니라 이 5판 전체를 같은 엔진에서 변화시킨다.

| 판 / 원본 키 | 대사집 사건 → 목표 | 맵·비주얼·난도 차이 |
|---|---|---|
| 06 `PARK_GOAL1` | 아래→위 골 **1회**; 득점 즉시 대사 | 중앙 인물이 블록 아치 뒤에 반쯤 가려짐. 양쪽 큰 직사각/정사각 블록으로 낮은 입구 노출. 기존 **블록 아래쪽 골대 그림 위치를 상향 조정** |
| 07 `PARK_JELLY` | 젤리 가속을 이용한 골 **2회**; 두 번째 골의 대사 | 두 갈래 젤리 경사·큰 젤리 장벽·아래 중앙 탄성 통로. 성공 후 다음 골 요구량이 표시됨 |
| 08 `PARK_MOVING` | 골대가 **실제로 좌우/자세 이동**하며 골 **1회** | 중앙 갈라진 움직이는 아치. 그림의 골반과 판정 중심이 함께 이동. 고정 타원 금지 |
| 09 `PARK_DEFENSE` | 금속 옆벽 반사 후 골 **2회** | 가운데 좁은 종방향 틈, 양편 금속 3타 기둥과 실제 이동 방벽. `금속 반사→골` 조합을 사건으로 기록 |
| 10 `PARK_FINAL` | **두 사람 교대**, 합계 **3골**, 교대 장면에서 대사 | 좌·우 2인 골대 그림, 서로 다른 의상·초상. 골마다 담당자가 바뀌는 실제 2인 타깃/피격 리액션. 독립적 세계대회 연출 없이 공원 행사로 마감 |

### 제3장 — 11~15 비밀의 방 / 블록 뒤 인물 발견과 몸 반사

**공통 엔진**: 숨은 인물을 블록 제거로 물리적으로 드러냄. 정면·후면 스쿼트 애니메이션과 몸 영역별 반사. 둘이 나오면 양쪽 독립 타깃. 두께 있는 벽과 작은 창을 활용해 **찾는 과정**이 드라마가 되어야 한다.

| 판 / 원본 키 | 대사집 사건 → 목표 | 맵·비주얼·난도 차이 |
|---|---|---|
| 11 `ROOM_REVEAL` | 벽을 걷어 **첫 공개**할 때 대사, 몸 반사 **1회** | 커튼처럼 맞물린 긴 블록. 가운데 뒤에 완전히 가려진 인물, 일부 제거 시 인물 윤곽 노출. 공개와 첫 반사는 별개의 사건 |
| 12 `ROOM_TWICE` | 같은 몸에 **2회 반사**, 2회째 대사 | U자 회랑 + 젤리 반사벽. 몸 부위별 각도 차이를 익히는 단계 |
| 13 `ROOM_DUO` | **두 사람에게 각 1회**; 두 번째 참가자 차례에서 대사 | 좌우 병풍형 벽, 두 인물 서로 다른 위치와 표정. 한쪽만 맞히면 종료 불가 |
| 14 `ROOM_GUARD` | 금속판을 피해 **3회 반사**; 통로를 통과한 유효 반사에 대사 | 이중 금속 세로문 + 비대칭 창. 금속 반사 여부를 사건으로 추적 |
| 15 `ROOM_FINAL` | 대사집은 **두 사람 각각 네 번**이라고 함 → 판정 `4+4`로 맞춤 | 두 층 교차 벽, 두 인물 간격 확장·축소, 연속 반사. **현 코드는 `2+2`라 수정 필수** |

### 제4장 — 16~20 촬영 스튜디오 / 바스켓과 몸 타격의 동시 연출

**공통 엔진**: 대사 원문이 명시한 **농구 림을 없애지 않는다.** 골 성공의 카메라/초상 리액션과 후면 캐릭터의 신체별 공 반사를 묶는다. 사용자 예시의 ‘엉덩이 맞춰 찰싹’은 림을 대체하는 임의 새 규칙이 아니라 **이 장면의 플레이 감각**으로 녹인다. 림은 위→아래 방향만 골 인정.

| 판 / 원본 키 | 대사집 사건 → 목표 | 맵·비주얼·난도 차이 |
|---|---|---|
| 16 `STUDIO_TAKE1` | 첫 테이크/아래 방향 **1골** → 표정 연출과 대사 | 카메라 프레임 같은 직사각 블록, 가운데 림·그 옆 캐릭터. 공이 몸에 닿는 반사와 카메라 리액션을 별도 표시 |
| 17 `STUDIO_MOVE` | **움직이는 림 1골** → 정확한 시점에 대사 | 림+캐릭터가 서로 다른 속도로 미끄러짐, 빛나는 긴 블록/무대 조명 띠 |
| 18 `STUDIO_DOUBLE` | **2골**. 대사 `하나 남았습니다`는 반드시 **첫 번째** 득점에서 | 양쪽 반사 벽과 한 림. 1차 성공 컷/표정이 바뀐 뒤 2차로 진입. **현재 코드의 완료 후 트리거 조건 제거 필요** |
| 19 `STUDIO_NG` | 금속 방해물을 뚫고 **2골**, 두 번째에 대사 | 금속 사이드 스크림, 림 앞 반사 통로. 강한 후면 리액션/효과음 구분 |
| 20 `STUDIO_FINAL` | **림 두 개 각각 1골**, 마지막 골에서 대사 | 좌/우 분할 세트와 **2명의 인물**, 각각 독립 림·표정. 한쪽 골만 여러 번 넣는 편법 방지 |

### 제5장 — 21~25 가이아 카지노 / 이동 장애물과 쪼그려 이동 반사

**공통 엔진**: 대사집의 `움직이는 금속판 → 두 개 반대 방향 → 독 → 가변 속도 → 잭팟`을 유지한다. 사용자가 제안한 **‘쪼그려 뛰면서 돌아다니는 인물’**은 이 판들의 장애물 사이 캐릭터 이동과 충돌 리액션에 추가한다. 점프가 금속/독 규칙을 대체하거나 대사와 동떨어진 메인 목표가 되지 않는다.

| 판 / 원본 키 | 대사집 사건 → 목표 | 맵·비주얼·난도 차이 |
|---|---|---|
| 21 `CASINO_BET` | **이동 금속판 1개에 공 반사** → 대사 | 반투명 칩 고리, 사이사이 움직이는 낮은 후면 인물. 이동 판정과 음성 리액션 분리 |
| 22 `CASINO_DOUBLE` | **서로 반대로 움직이는 금속판 2개** → 교차 반사 | 엇갈린 계단형 통로, 반대 위상 장애물 두 개. 인물은 몸 낮춰 이동하며 통과를 방해/돕는다 |
| 23 `CASINO_POISON` | 독 마크가 **주변 블록을 시간차로 2회 녹임** → 실제 연쇄 시 대사 | 달팽이형 벽, 작은 사각 독칩을 외곽에 심음, 효과가 커지며 인물 노출 |
| 24 `CASINO_TIMING` | 장애물 **속도가 계속 바뀜** → 첫 변화가 플레이에 실제 반영될 때 대사 | 움직이는 열린 문/비대칭 회랑, 점프 인물과 장애물 템포 차로 타이밍 난도 상승 |
| 25 `CASINO_FINAL` | **잭팟 2회**, 두 번째에 대사 | 중심 잭팟 2개의 독립 타깃, 이동 판+독+폭탄 복합 맵. 작은 독/큰 진열 블록의 크기 대비 |

### 제6장 — 26~30 캔디 농장 / 울타리와 핀

**공통 엔진**: 울타리 블록을 깨서 **핀을 노출/쓰러뜨리는** 체험. 인물은 울타리 뒤 현장 진행자로 나타나며 단계별 놀람·응원 초상을 사용한다. 핀은 실제 물리 타깃이며 관성/넘어짐이 보인다.

| 판 / 원본 키 | 대사집 사건 → 목표 | 맵·비주얼·난도 차이 |
|---|---|---|
| 26 `FARM_PIN1` | 울타리 제거 후 **핀 1개 전도** → 대사 | 낮은 목재 울타리와 큰 단일 핀, 정사각형 목재 틈 |
| 27 `FARM_PIN2` | **좌우 두 구획/각 1핀**, 두 번째 핀에서 대사 | 왼쪽·오른쪽 긴 울타리 두 벌, 두 핀 분할 표시 |
| 28 `FARM_PIN3` | **핀 3개 + 폭탄 3개**; 폭발 후 핀 연속 전도에서 대사 | 삼각 핀 배열, 연결 폭탄 핵과 목재 진열 파편 |
| 29 `FARM_MOVE` | **움직이는 울타리**가 열릴 때 통과/핀 3개 | 두 줄 움직이는 긴 블록, 한쪽만 열리는 타이밍 창 |
| 30 `FARM_FINAL` | **핀 5개**, 폭탄으로 먼저 길 열기 → 연쇄 전도 | 반원형 5핀과 전면 폭탄 쐐기, 전도를 1~5로 세서 전부 표시 |

### 제7장 — 31~35 호스트 클럽 / 네온과 스쿼트 리듬

**공통 엔진**: 네온 2타→번개→스쿼트(서기 포함)→고속 스쿼트→**서기 동작 없이 쪼그린 점프**로 진화. 프레임·몸 타격·BGM 90/120/150 BPM이 동기화되며, 쪼그려 점프에는 새 원화 대신 기존 `jump/frame_00..03.png` 사용.

| 판 / 원본 키 | 대사집 사건 → 목표 | 맵·비주얼·난도 차이 |
|---|---|---|
| 31 `CLUB_NEON` | 네온 **첫 타 소등/흑백, 두 번째 파괴** → 첫 피격 대사 | 무대 조명처럼 수직 네온 띠, 색이 꺼진 뒤 리액션과 불 켜짐 대비 |
| 32 `CLUB_CHAIN` | **번개 두 번 연결** → 전기 연쇄 대사 | 마디형 네온 선과 번개 2개를 실제 이웃으로 배치, 다중 블록 방전이 보임 |
| 33 `CLUB_SQUAT` | `1·2·3→일어서기` **스쿼트 박자**, 몸 반사 1회 | 중앙 큰 캐릭터/몸 부위 히트박스, 블록 사이 창으로 포즈가 보임 |
| 34 `CLUB_FAST` | `1·2·3·3·2·1` **빠른 반복**, 연속 몸 반사 2회 | 좁아진 블록 고리+움직이는 장벽, 빠른 프레임과 타격 사운드/초상 연동 |
| 35 `CLUB_FINAL` | **두 사람, 쪼그린 점프 교대**, 각각 2회 몸 반사 | 좌우 2인 분리 무대, 각각 독립 점프 위상. **서 있는 프레임 없이 점프**. 둘이 번갈아 반응하고 교대 대사 |

### 제8장 — 36~40 가이아 경찰서 / 앞서 배운 시스템의 복합

**공통 엔진**: 새로운 생뚱맞은 규칙이 아니라 앞 7장의 물리·사운드·인물·배치 결합. 제복 초상으로 들어와 플레이 의상으로 전환했다가 **0.1초 만에 근무 복귀**하는 세계관 연출을 가장 확실히 보여 준다.

| 판 / 원본 키 | 대사집 사건 → 목표 | 맵·비주얼·난도 차이 |
|---|---|---|
| 36 `POLICE_TEST` | **5개 블록 재질**을 구별하며 격파 → 복합 파괴 대사 | 5재질 색 구획/사각형 패치워크, 가운데 인물이 조금씩 드러나는 계단 |
| 37 `POLICE_BARRIER` | **이동 장애물 2개**, 좁은 틈 회피 시 대사 | 지그재그 금속 복도, 폭탄·독 소형 블록과 반사 방벽 |
| 38 `POLICE_DUAL` | **축구 1회 → 농구 1회, 순서 필수**; 두 번째 종목 성공 때 대사 | 블록 아치 안 2종목 표적, 이미 성공한 골은 가시적 체크. **현 코드는 순서 검사가 없어 변경 필수** |
| 39 `POLICE_PRACTICAL` | **핀 각각 1개×3 + 몸 반사 2회**, 마지막 반사 때 대사 | 좌우 핀 3개를 가린 벽+가운데 반사 캐릭터. 목표마다 서로 다른 타격 영역 |
| 40 `POLICE_ENDING` | 블록 **90% 제거 후 하트 등장, 3회 명중**. 두 번째 때 `trigger`, 마지막 후 `extras`+`clear` | 위에서 아래로 열리는 하트 문, 두 캐릭터 원화/복귀 초상, 색이 사라지고 하트만 남는 장면. 업무 복귀로 끝남. 별도 세계 결승전 서사 없음 |

## 4. 기존 구현과 대사의 **확인된 충돌** (수정 순서와 무관하게 기록)

| 항목 | 현재 구현 | 설계 시 반드시 고칠 것 |
|---|---|---|
| 40판 순서 | 모든 장소를 8판 단위로 뒤섞는 `circuit` | 원본 장면 01~05, 06~10 … 36~40 묶음. 진행도/이어하기 세이브 이전 규칙과 충돌할 수 있으므로 마이그레이션 테스트 |
| 골대 | `PARK_GOAL1` **한 판만** 그림/동적 판정 적용, 그림 시작점이 블록 **아래** | 06~10 공통 재사용, 블록 뒤로 상향, 2인/이동/다골 대응 |
| 이인 교대 | `PARK_FINAL`에 축구 목표 1개×3회, 다른 성별 그림만 번갈아 바꾸는 방식 | 실제 **2인** 아트·히트박스·담당 차례가 따로 존재 |
| 비밀의 방 마지막 | `ROOM_FINAL` `reflect:[2,2]` | 대사 숫자에 맞춰 `[4,4]` |
| 촬영 18판 | `STUDIO_DOUBLE` 사건 대사를 2골 모두 채운 후에만 재생 | ‘하나 남았습니다’는 **첫 번째 골**에 재생 |
| 몸 반사 | `reflect` 중심의 공통 타원, 기존 작은 후면 스프라이트 | 신체 4영역과 4프레임 맞춤 판정, 사운드와 초상 리액션 연결 |
| 점프 | `hop` 플래그와 예전 108×162 스프라이트 약간의 상하 이동 | 기존 신형 점프 4프레임, 이동 좌표와 맞춘 반사 판정 |
| 38판 복합 | `soccer`·`basket` 순서를 자유롭게 기록 | 대사대로 축구 → 농구 순서 검증 |
| 40판 끝 | 일부 `extras`만 결과 화면에서 출력; 이벤트 경로 특수 처리 | **트리거/추가 대사/종료 대사** 세 개 다 보여 줄 것 |
| 초상 | 속옷 기본 얼굴 4종만 연결, 나머지 의상·치어 이미지 대부분 무시 | 도입 정장/왕실복 → 속옷 → 다양한 표정 → 일상 복귀 컷 |
| 폭발/전기/독 이벤트 | 장면 스크립트가 요구하는 ‘연쇄’보다 단일 첫 피격 이벤트가 뜨기도 함 | 실제 연쇄 성립 조건에만 전용 `trigger` 재생 |

## 5. 제작 단위와 완료 조건: 다음에 무엇을 **하나씩** 할 것인가

### 1차 — **설계 승인** (현재 단계)

- 이 문서의 40행 장면·게임 목표·인물·블록 실루엣을 최종 기준으로 확정한다.
- 유저가 이미 준 에셋·대사 파일 경로를 확정한다. 자산 재요청·대사 재작성은 작업 항목이 아니다.
- `sceneKey`·스테이지 ID·대사 원문 해시를 고정해, 이후 코드 작업이 내용 누락을 일으키지 않게 한다.

### 2차 — **01~05만 실제 구현** (승인 이후, 다른 35판은 건드리지 않음)

1. 마트 공통 인터페이스: 옷 입고 등장→원본 대사 전문→속옷 전환→게임→트리거→종료/업무복귀.
2. 5개 고유 보드 스케치와 블록 PNG 크기·충돌 영역 일치, 움직임은 설계된 위치에만. 01판 실제 파괴 대상 60개의 숫자 일치.
3. `solid/jelly/metal/bomb/quickChain` 사건 정확도와 원문 대사 UI 노출 테스트.
4. 01~05 **실제 플레이, 큰 화면·세로 화면, 첫/중간/클리어 이미지** 검수. 이전 맵/진행도 저장 상태가 깨지지 않는지 검사.
5. 문서에 **구현 체크(파일·커밋·테스트·미해결 사항)**를 남기고 GitHub 반영. 이 상태가 다음 대화의 시작점이 된다.

### 이후 5판 단위 (각 장 완성할 때마다 멈추고 검수)

06~10 골대 1인→이동→2인 · 11~15 가림/다중 몸 반사 · 16~20 스튜디오 림+몸 리액션 · 21~25 이동/점프/독/잭팟 · 26~30 핀/울타리 · 31~35 네온/스쿼트/점프 리듬 · 36~40 기존 기믹 복합과 업무복귀.

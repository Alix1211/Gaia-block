## 공통 연출 / 원본 보존

- 대사 키는 원본 그대로. 도입부에 **기존 옷 입은 초상화**(`P03`/`P05`)가 나타나며, 남성/여성 대사를 전문 출력한다. 시범판 시작을 확인할 때 기존 속옷 초상(`P01`/`P02`)으로 전환. 도입 중에는 물리를 정지한다.
- 원본 후면 스쿼트 4프레임, 골대 2프레임, 쪼그린 점프 프레임을 `js/renderer.js`에 직접 로드한다. 새로운 여성 그림을 만들어 대체하지 않았다.
- 공이 신체에 닿는 곳에 따라 좌/우 반사각과 음색·보유 표정이 다르다. 골대는 독립 득점이고 일반 몸 타격은 득점으로 취급하지 않는다(11판은 원본의 `reflect` 목표를 채움).
- 기존 `slap-1..3`, 다른 효과음과 `voice`를 재사용한다. **전경 블록에 먼저 닿은 공이 같은 프레임에 뒤의 몸까지 맞힌 것으로 처리하지 않는다.**
- 시범판은 메뉴에서 직접 접근하고, 완료해도 본편 진행을 해금하지 않는다. 스테이지 번호와 대사 키를 원본 순서로 다시 정렬했다. 기존 저장값은 새 `v2` 키로 매핑해 읽는다.

## 이미지 검수

`docs/previews/PROTOTYPES_06_11_21.jpg` — 각 판의 초기/다른 자세를 **실제 게임 엔진·렌더러와 기존 배경/이미지**로 800×800 해상도에 렌더링한 3열×2행 비교 이미지의 축소본(저장소용). 원본 해상도 `PROTOTYPES_06_11_21.png`와 개별 PNG는 스크립트로 재생성할 수 있다.

- **06**: 인물이 블록 아래가 아니라 중앙 안쪽에 있고, 넓은 빈 통로와 골대 몸이 보인다. 동작 2컷과 타격 원 위치가 함께 바뀐다.
- **11**: 커튼처럼 배치한 블록 사이로 상체·하체가 가려졌다 드러나는 인물이 보인다. 서기/쪼그리기 2자세가 시각적으로 다르다.
- **21**: 중앙 통로와 이동 금속판 사이에서 쪼그린 캐릭터의 위치·높이가 변한다. 긴 금속 블록·작은 칩·일반 블록이 분리돼 보인다.

이 이미지는 **코드 기반 렌더링 검수**다. 스마트폰·태블릿에서 손으로 플레이해 밸런스/소리/터치 조작을 확인했다고 주장하지 않는다.

## 아직 하지 않은 것 / 다음 결정

1. **난도 확정 안 함**: 드롭율/효과 밸런스, 블록 보드 변형, 실제 플레이 소요시간과 손실률 측정 필요.
2. **나머지 37판 재설계·재연출 안 함**: 현재 06·11·21 세 판만 신형 동작과 그림을 통합. 10의 2인 골대, 16의 스튜디오, 20의 2인 림, 31~35 리듬은 다음 검증 대상 후보이지 이번 완료 범위가 아님.
3. **세로/Android 실기 검수 안 함**: 기존 화면 잘림 문제는 남아 있음. 새 초상화 재요청 없이 기존 이미지의 배치/CSS 개선 필요.
4. **21판 캐릭터 피격은 선택적 반사**: 현재 카지노 원본 대사의 메인 성공 사건은 **금속판 반사**다. 캐릭터 충돌을 필수 목표로 만들지 여부는 나중에 게임 감각과 대사 의미를 함께 검토해야 한다.
5. 원본 EX-HARDCORE 대사집은 그대로 유지했다. 사용자 문장 누락 여부는 UI 자동 테스트 외에 실제 화면 전체 길이 검수가 남음.

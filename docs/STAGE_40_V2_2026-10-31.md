# GAIA CITY · HEART BREAKER — 40판 상세 설계 v2

2026-10-31 / **기획 확정 범위: 8개 장소 × 장소별 5판 = 40판.** v0.11.0에서 핵심 충돌 규칙과 40판 데이터/목표 판정은 구현했으며, 원본 캐릭터 신규 모션·손 배치·아트 마감·실기기 밸런스는 남아 있다. 기존 `STAGE_PLAN_V1_2026-10-31.md`의 재질·기믹을 계승하고, 8판 구상을 40개의 고유 판으로 확장한다.

## 0. 세계관·제작 원칙

- 가이아 시티의 **자발적 웰니스 이벤트**. 성인 여성 참가자들이 신청하고 최고 난도를 요구한다. 처벌·검거·강제행사의 이야기로 뒤집지 않는다.
- 상황은 과장되고 분위기는 명랑하다. 여자→남자 존댓말·청유형, 남자→여자 반말과 직업적 비즈니스 매너의 대비. 종료 직후에는 0.1초 만에 평상 업무로 복귀한다.
- 기존 캐릭터의 얼굴·의상·헤어스타일을 임의 변경하지 않는다. 사용자 제공 갈색 웨이브/붉은 의상, 검은 머리/분홍 의상 원본을 사용한다.
- **현재 게임은 v0.11.0 40판 규칙 구현판**. 기존 투명 캐릭터 컷과 캔버스 도형으로 목표를 임시 시각화하며 사용자 제공 신규 원본 프레임은 아직 교체하지 않았다.
- 배경 PNG는 기존 장소별 8장만 사용. 신규 장치는 투명 PNG로 오버레이하며 원본 에셋을 덮어쓰지 않는다.

## 1. 40판 공통 규칙

| 항목 | 설계 |
| --- | --- |
| 구분 | 8개 장소(챕터) × 각 5개 라운드. 전역 번호 01~40, 장소 내 난도 1~5 |
| 클리어 | 각 판마다 정해진 **블록 파괴율**과 **특수 목표**를 모두 달성. 파괴율은 `시작 시 파괴 가능 블록 수` 대비 실제 파괴 수이며 불가파괴 금속은 분모에서 제외 |
| 진행 저장 | **한 판 단위** 클리어 기록, 해당 판 재도전. 최고 점수와 별도로 마지막 해금 판 저장. 기존 사용자 저장과 충돌하지 않는 신규 키 사용 |
| 플레이 시간 | 1판 약 2~4분 목표. 긴 후반 판도 마지막 블록 하나를 찾아 헤매지 않도록 80~90% 파괴 목표 사용 |
| 블록 | 솔리드(1타), 젤리(2타·첫 타 공 +8% 상한 1.4배), 우드(1타·조각), 금속(3타 또는 불가파괴), 네온(첫 타 흑백·2타 파괴) |
| 마크 | 폭탄(반경 1.5칸, 연쇄 최대 2단), 독(주변 시간차 피해), 번개(최근접 2개 전이), 변색(설정 횟수마다 색 변경 후 파괴) |
| 목표 판정 | 골/핀/캐릭터 접촉을 블록 피해와 별도 오브젝트로 취급. 같은 충돌을 2회 집계하지 않고 목표 성공 시 잠깐의 시각 피드백만 준 뒤 공을 안전하게 되돌림 |
| 난도 증가 | 단순 속도·내구도 증가 대신 **배치/이동/복합 목표/타이밍**을 점진적으로 추가. 불가파괴 장애물이 공 경로를 영구 봉쇄하지 않게 배치 |
| 연출 | 짧은 효과음과 0.7~1초 측면 리액션. 파티클·화면 흔들림 중복 제한. 게임판을 가리는 큰 말풍선 금지 |

### 레이아웃 좌표 규약

- 설계 기준 게임판 10열 × 7~10행. 각 표의 `7×10`은 `7행, 10열`을 뜻한다. 빈 셀·긴 블록을 섞으며 수량은 최초 제작 목표치다.
- 상단은 목표 및 특수 오브젝트 영역, 하단은 공 반사 공간. 농구는 위→아래 통과, 축구는 아래→위 통과 판정.
- 움직이는 불가파괴 금속은 한 번에 1~3개. 이동 속도는 초반 70px/s, 후반 최대 110px/s 설계. 목표에 들어가는 필수 통로는 최소 공 지름 2.5배 유지.
- `목표 80% + 골 1`과 같은 조건은 **AND**. 목표는 달성했지만 블록 파괴율이 부족하면 숫자/아이콘으로만 남은 목표 표시.

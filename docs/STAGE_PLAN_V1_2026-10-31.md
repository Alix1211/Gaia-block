# GAIA CITY · HEART BREAKER — 8스테이지 구성안 v1

2026-10-31 · **게임에 아직 적용하지 않은 디자인/기믹 설계 문서**. 기존 v0.10.1 게임 동작과는 구분한다. 현재 장소별 배경 8장을 그대로 사용하는 구상이며, 신규 오브제는 투명 PNG로 위에 얹는다.

## 1. 블록 구성 원칙

- 한 스테이지의 주요 공간은 **블록이 빽빽하게 차 있는 7~10행 × 10열**. 기본 실루엣은 정사각형·일반 직사각형·2~3칸 긴 직사각형을 혼합한다.
- **재질(material)**과 **추가 마크(modifier)**는 별개의 데이터다. 같은 젤리도 일반/폭탄/독 마크가 붙을 수 있다. 과한 중복은 피한다.
- 재질별 기본 규칙:

| 재질 | 타격/파괴 횟수 | 맞았을 때 보이는 변화 | 공과의 상호작용 |
| --- | --- | --- | --- |
| 파스텔 젤리 | 2회 | 첫 충돌 시 흔들림·눌림, 두 번째에 터짐 | 첫 충돌 때 공 속도 +8%, 상한은 스테이지 기본 속도의 1.4배; 계속 누적되지 않도록 제한 |
| 핑크 우드 | 1회 | 분할선에 따라 조각 3~5개가 튀는 짧은 파괴 연출 | 일반 반사 |
| 핑크 금속 | 일반형 3회, 고정형 무한 | 찌그러짐→큰 금→파괴, 고정형은 타격 반짝임만 | 단단한 반사, 고정형은 절대 클리어 잔여 수에 넣지 않음 |
| 네온 | 2회 | 첫 충돌에 불이 꺼져 회색/흑백, 두 번째에 파괴 | 일반 반사, 불 꺼진 상태가 명확하게 보임 |
| 솔리드 | 1회 | 즉시 깨짐 | 기본 반사; 일부 특수 변형은 피격할 때 색 전환 |

- **특수 마크**는 재질 위에 스티커처럼 작게 붙인다. 기본 모델이 아닌 무늬/효과의 덧씌우기다.
  - 폭탄(💣): 해당 블록 파괴 시 반경 약 1.5칸의 다른 파괴 가능 블록에 1회 피해. 연쇄 폭발은 최대 2단계까지.
  - 독(☠): 해당 블록이 맞으면 좌우 인접 블록 2~4개에 0.6초 간격으로 1회씩 총 3회 피해. 초록/민트 액체가 서서히 녹이는 연출. 고정형에는 피해 없음.
  - 번개(⚡): 파괴 시 가장 가까운 2개의 블록에 1회 피해. 기존 전기 전이 함수를 재사용할 수 있으나 **블록 자체의 속성**으로 작동하도록 연결해야 한다.
  - 변색(🎨): 첫 충돌 시 다른 색으로 전환. 1회 파괴하는 일반 솔리드와는 별도 변형이며, 변색 횟수/파괴 조건을 스테이지 데이터로 지정한다.

## 2. 신규 스테이지 기믹과 판정

**골대 시각 콘셉트 확정 메모 (사용자 지시):** 축구형 골대는 흔한 축구 네트 그림이 아니라 **엎드린 성인 여성 캐릭터를 활용한 코믹한 골대**로 표현한다. 아래의 골포스트·통과 판정 수치는 초기 물리 설계값이며, 캐릭터 이미지의 실제 윤곽·골 인정 영역은 시안에서 조정한다. 일반 골대 그림으로 임의 대체하지 않는다. 농구형 림은 별도 기믹으로 유지한다.

1. **축구 골대**: 게임판 상단에 폭 150~180px 골대. 양옆 골포스트는 공을 반사하고, 중앙 골 영역에 **아래에서 위로** 공 중심이 통과하면 골로 판정. 득점 시 잠깐 정지한 뒤 공을 아래로 다시 튕겨준다. 시작 단계는 고정 골대, 후반 단계는 좌우 이동 가능.
2. **농구 골대**: 상단 1/3 지점의 가로 링(폭 약 105~125px), 좌우로 약 60px/s 이동. 공이 림 안쪽을 **위에서 아래로** 통과하면 득점. 충돌 판정은 링의 보이는 구멍보다 약간 관대하게 한다.
3. **좌우 이동 불가파괴 금속**: 폭 약 1~3칸, y=200~360px 사이 수평왕복, 속도 70~110px/s. 공은 튕기되 블록은 남음. 이동 중 충돌은 현재 위치+이동 속도를 계산해 관통·연속 충돌을 방지한다.
4. **캐릭터 공개 영역**: 미리 배치한 중앙 블록 보호막이 사라지면 그 자리 뒤에 있는 성인 여성 캐릭터 PNG가 드러난다. 지정된 작은 반사 영역(예: 허리·엉덩이 주변)에 공이 닿으면 방향이 바뀌고 속도 +12%, 대사·간단한 흔들림. 동일 구역 0.8초 재발동 금지, 공 속도 최대 1.5배. 캐릭터가 블록을 가리거나 공 경로를 완전히 막지 않도록 캐릭터는 게임판 **뒤 레이어**로 둔다.
5. **골프핀**: 블록이 보호하는 3~5개의 핀. 주변 보호 블록을 제거한 뒤 공에 핀이 맞으면 넘어지는 애니메이션과 점수를 준다. 핀은 블록과 별개 오브젝트다.
6. **블록 연쇄 파괴 리액션**: 기존 전체 누적 콤보와 구별해 **1.2초 안에 블록 5개 이상 실제 파괴** 시 옆 캐릭터 PNG 0.7~1.0초 등장 + 작은 `찰싹찰싹` 만화 말풍선. 재등장 대기 5초. 소리·화면 흔들림 과다 중복 금지.

### 난이도 기본값

- 현재 엔진의 단계별 기본 구속도는 3.8 / 4.05 / 4.3 / 4.0 / 4.5 / 5.0 / 5.5 / 6.0. 젤리 가속이 큰 변수가 되므로 테스트 후 상한을 조절한다.
- 축구·농구·캐릭터 스테이지는 잔여 블록이 조금 남아 있어도 목표를 완수하면 클리어할 수 있게 한다. **끝의 한 개 블록 때문에 지루해지는 상황**을 피하려는 의도다.
- 점수는 기본 블록 점수에 더해 축구 골 +1,000, 농구 골 +1,500, 핀 +500, 특수 하트 +2,000(가안). 스테이지 점수 밸런스는 후속 조정.

## 4. v0.10.1에 실제 있는 기능과 새로 필요한 기능

### 코드에 있음

- 8개 기존 장소·배경, 기본 벽·패들·공 충돌, 발사/목숨/일시정지/결과 화면.
- 블록 타입: 1/2/3회 내구도, 폭탄, 파괴 불가; 폭탄의 **반경 피해 1회**. 강화 블록은 손상된 유리 스프라이트로 전환됨.
- 4스테이지부터 **일부 파괴 가능한 블록**이 소폭 좌우 왕복(진폭 7~15px). **움직이는 파괴 불가 방패는 아직 없음**.
- 분열공, 레이저, 패들 확장/축소, 관통공, 보호막, 슬로우, 자석, 유도탄, 전기, 생명 회복 등 **11종 효과**.
- 전기 활성 시 인접 2개 블록 피해, 소규모 파티클, 화면 흔들림/흰색 플래시, 공 궤적, UI 캐릭터 표정·대사, 콤보 숫자.
- 하단 단축 아이템 3개(하트·얼음·번개 각 3회), 점수/최고점/이어하기, 3종 BPM BGM과 충돌·음성 사운드.

### 아직 없음 — 추후 구현 필요

- 재질별 이미지를 실제 블록 상태에 매핑(현재는 유리 스프라이트), 젤리 가속/2회 파열, 우드 조각, 금속 단계별 찌그러짐, 네온 첫 타 흑백/둘째 파괴, 솔리드의 변색.
- 축구/농구 링 판정과 득점 카운터, 핀 충돌·넘어짐, 캐릭터 충돌 영역과 자동 공개.
- 충분히 큰 폭으로 좌우 왕복하는 **파괴 불가 방해 블록**.
- 독의 시간차 주변 피해, 블록별 전기 마크, 시간창 기반 연쇄 파괴 리액션, 최종 하트 타깃.
- 각 스테이지의 복합 클리어 목표. 기존 코드는 단순히 **파괴 가능 블록이 0개**면 클리어한다.

## 5. 구현 순서 제안

1. 블록 재질별 기본 타격·파괴와 이미지 적용, 속도 상한·다중 충돌 안전장치.
2. 특수 마크(폭탄/독/번개)와 이동 고정 금속 방해판.
3. 스테이지 목표 오브젝트: 축구 골대→농구 림→핀.
4. 캐릭터 공개/특정 반사 영역·측면 리액션.
5. 기존 8개 장소에 완성형 스테이지를 연결하고 장시간 플레이·클리어 테스트.

**아직 게임 코드는 변경하지 않는다. 디자인과 룰을 확정한 후 적용한다.**

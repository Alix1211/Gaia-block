# GAIA CITY: HEART BREAKER — v0.13.0 기믹 실험 3판

가이아 시티 세계관의 터치형 블록격파 게임입니다. **40개 장면과 대사 원본은 보존**하지만, 먼저 서로 다른 기믹 3판을 실제 게임에 연결해 검증하고 있습니다. **나머지 장면의 난도·판면은 확정하지 않았습니다.**

## 실행

1. ZIP을 **압축 해제**합니다.
2. 폴더 안 `index.html`을 Android Chrome 또는 PC Chrome으로 엽니다. 별도 서버, 가입, 인터넷 연결이 필요하지 않습니다.
3. 메뉴의 **`06 · 골대` / `11 · 숨은 반사` / `21 · 쪼그려 이동`** 버튼으로 각 기믹을 바로 시험할 수 있습니다. `GAME START`는 기존 40판 순서로 시작합니다.
4. 옷 입은 등장 초상과 대사를 확인한 뒤 **시작**을 누르면 인게임 의상으로 전환됩니다. 화면을 탭해 공 발사 → 손가락을 좌우로 움직여 패들 제어. 시범판 성공은 본편 진행 기록을 건드리지 않습니다.

PC에서는 마우스 이동, 방향키 또는 A/D 이동, 스페이스 발사, P/Esc 일시정지를 지원합니다.

단일 파일 오프라인 판이 필요하면 `node tools/build-standalone.mjs`를 실행하세요. 저장소 상위 폴더에 `GAIA_Heart_Breaker_v0.13.0_Three_Prototypes_Standalone.html`이 생성되며, 새 정장/속옷/애니메이션 이미지와 오디오까지 파일 하나에 묶습니다.

## 구현된 범위

- **시안 기준 화면:** 검은 배경과 상단 정보 프레임을 제거했습니다. 현재 가로·세로 캐릭터 레이아웃의 잘림 현상은 아직 수정하지 않았습니다.
- **밝은 배경:** 장소별 배경을 화면 전체에 한 장만 사용하고 유리 게임판 너머로 그대로 비칩니다.
- **40개 대사 장면:** 원본 `sceneKey` 순서대로 01~40을 다시 배치했습니다. **06=골대, 11=비밀의 방, 21=카지노**. 현재 3판만 새로운 실물 캐릭터 기믹을 검증 중이며, 나머지 판은 기존 임시 규칙/배치를 유지합니다. 난도 최종 확정은 아이템 드롭·블록 배치 실험 이후입니다.
- **06 골대:** 초선의 엎드린 자세 2프레임을 **블록 안쪽 뒤에** 배치했습니다. 그림과 판정 고리가 함께 움직이며 아래→위 골 1회 + 기존 임시 파괴율 조건을 요구합니다. 긴 블록 150×32, 정사각형 34×32, 일반 73×32이 함께 등장합니다.
- **11 숨은 반사:** 제공된 새 후면 스쿼트 4프레임의 캐릭터가 벽 뒤에서 드러납니다. 상체/허리/골반/허벅지의 **서로 다른 움직이는 충돌 영역**과 반사각·효과음·초상 반응을 시험할 수 있습니다.
- **21 쪼그려 이동:** 움직이는 금속판 대사/물리를 유지하면서, 제공된 쪼그린 점프 프레임의 인물이 좌우로 움직여 공을 반사합니다. 선 자세는 사용하지 않습니다.
- **기존 초상과 대사 실제 연결:** 3개 기믹 시범판은 정장/왕실복으로 등장하여 원본 도입 대사를 보여주고, 시작을 누르면 속옷 초상으로 전환, 피격 때 표정이 변하며 성공 시 기존 치어/일상 복귀 컷을 보여 줍니다. 대사 도중 게임 물리가 진행되지 않습니다.
- **재질·장치:** 솔리드/젤리(첫 타 가속)/우드(조각)/금속(3타 또는 불가파괴)/네온(첫 타 흑백) 및 폭탄·독·번개·변색 마크를 추가했습니다.
- **독립 목표:** 축구 골대(아래→위), 농구 림(위→아래), 캐릭터 반사, 캔디 핀, 잭팟 표적, 40판 마지막 하트 3회 명중을 따로 판정합니다. 움직이는 금속과 이동 목표도 있습니다.
- **저장 호환:** 장면 순서 변경에 따라 저장 버전 `v2`를 사용하고, 구 40판 `v1`의 마지막 진행 장면을 새 번호에 대응해 읽습니다. 기존 8장소 저장값도 읽습니다.
- **대사 설정:** 톱니바퀴 설정에서 NORMAL(기존 40판 대사집) / EX-HARDCORE(사용자 제공 원문) 선택. 두 모드 모두 40판 장면 키에 연결하며, 선택은 기기에 저장됩니다. 게임 난도와 진행 기록에는 영향을 주지 않습니다.
  - 원고: [`NORMAL`](docs/DIALOGUE_40_V1_2026-10-31.md) / [`EX-HARDCORE`](docs/DIALOGUE_40_EX_HARDCORE_USER_2026-10-31.md). 게임용 데이터는 `node tools/compile-dialogues.mjs`로 생성합니다.
- **블록 v0.11.2:** 5개 재질 × 4개 형태의 원본 PNG 20개를 투명 여백만 잘라 별도 보존하고, 40판 전체에서 실제 에셋을 그립니다. 기본 직사각형과 색상 변형은 73×32 판정, 폭탄·독·번개·변색 표시 블록은 34×32 정사각 판정, 움직이는 파괴 불가 금속 바는 130×27 판정으로 그림과 실제 충돌 영역을 일치시켰습니다. 3타 금속의 균열, 2타 네온의 흑백 전환, 2타 젤리의 변형·속도 증가, 1타 우드·솔리드의 파괴를 구분합니다. 기존 유리 스프라이트는 저장소에서 유지하되 신규 40판에서는 사용하지 않습니다.
- **공과 패들:** 일반 패들까지 포함해 원본 공·패들 스프라이트를 그대로 사용합니다. 공에는 가벼운 보라·핑크 궤적이 남습니다. 길이 변경/레이저/자석/전기/보호막 등 상태별 외형을 지원합니다.
- **세로 화면 아이템:** 게임판 아래 하트·얼음·번개 3개의 단축 아이템이 있으며, 한 판에 각각 3회 사용할 수 있습니다.
- **아이템 11종:** 분열공, 레이저, 확장, 관통공, 보호막, 감속, 자석, 유도탄, 축소, 전기, 생명 회복.
- **리액션:** 성인 비율 캐릭터의 표정 컷과 말풍선, 충돌 합성음, 콤보 반응.
- **편의:** 터치 조작, 일시정지, 소리 토글, 스테이지 이어하기, 최고 점수 로컬 저장.
- **v0.9.1 최적화:** 블록별 매 프레임 그라디언트·광원·선 그리기를 제거했습니다. 배경 8장 동시 로딩을 없애고, 공 잔광을 축소했으며, 프레임 저하 시에도 물리가 지나치게 느려지지 않도록 시간 단위를 보정합니다.
- **v0.10.0 음원:** 사용자 제공 BGM 3곡을 스테이지 1~2(90 BPM), 3~5(120 BPM), 6~8(150 BPM)에 연결했습니다. 짧게 추출한 `찰싹` 효과음 3종을 블럭 충돌에 사용하고, 캐릭터 음성 7종을 반응에 연동합니다. 음성이 나올 때 BGM은 자동으로 작아집니다. 일시정지·복귀·음소거에서도 음악 상태가 동기화됩니다.
- **v0.10.1 클리어 복구:** 마지막 블럭 파괴 즉시 결과창을 표시하고, 캔버스 렌더링 오류가 한 번 나도 다음 프레임이 중단되지 않게 보완했습니다. 다음 스테이지 진입은 음원 오류와 분리했습니다.

## 남은 작업

- **태블릿 실기기 시각 점검:** 신규 06·11·21판은 실제 엔진/렌더러를 실행한 `docs/previews/PROTOTYPES_06_11_21.jpg`로 2자세씩 화면 검수했습니다(고해상도 PNG는 로컬 재생성 가능). 실제 Android Chrome에서 화면 크기·성능은 아직 검증하지 못했습니다.
- **나머지 판의 캐릭터 연결:** 이 세 대표판 외 골대/캐릭터 반사는 기존 임시 컷을 사용합니다. 스쿼트/점프 전체 40판 통합은 **미구현**입니다.
- **스테이지 레이아웃 미술 마감:** 손으로 만든 첫 8판 이외의 32판은 임시 고정 시드입니다. 장면별 등장 인물 수·교대 시나리오도 미완성입니다.
- **플레이 밸런스:** 자동화 충돌 테스트를 통과했지만 Android 실기기 플레이 및 40판 통과 시간 검증은 아직 하지 않았습니다.
- 스테이지별 대사 시작/이벤트/클리어를 화면에 연결했습니다. 기존 음성 7개는 재사용하며, 신규 대사 전체에 대한 전용 음성은 아직 없습니다.

## 기술 및 저작권

플레이 물리와 기본 스테이지/아이템 로직은 `Arkanoid New Era` (MIT, iltempe, 2026)를 기반으로 확장했습니다. 일부 보조 합성 효과음은 `DX-Ball` (MIT, Kuldeep Singh aka Aby, 2026)를 참고했습니다. 각각의 MIT 라이선스 파일을 동봉합니다. 여성 캐릭터, 배경, 스프라이트 및 신규 음원은 사용자 제공·대화 중 제작한 에셋입니다. 원본 긴 WAV는 변환하지 않고 별도 보존하며, 게임에는 짧게 추출한 MP3만 포함했습니다.

테스트: `node tools/test-stages40.js`는 40판 목표·소재·특수 판정·전체 클리어 가능성을, `node tools/gaia-smoke.mjs`와 `node tools/ui-smoke.mjs`는 엔진·UI·일시정지·오프라인 구성을 검사합니다. 단, 실기기 조작감과 전체 수동 클리어 플레이는 추가 확인이 필요합니다.
